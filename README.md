# Покупки в Груше — дашборд на d3.js + Vue.js

Дашборд потребления клиента сервиса доставки продуктов (09.2021 – 08.2026).

**Что показывает**

- **Ключевые метрики** за выбранный период: количество заказов, сумма трат, средний чек, средняя скидка, число разных товаров.
- **Динамика по месяцам** — три синхронизированные панели: количество заказов, сумма трат и средняя скидка. Наведение показывает значения месяца, выделение мышью диапазона пересчитывает весь дашборд за этот период.
- **Категории** — траты / число заказов / штуки по категориям; клик по категории фильтрует товары.
- **Частота против трат** — каждый товар как точка (лог. шкалы), лидеры отмечены картинками.
- **Топ-10 товаров** — что клиент заказывает чаще всего и на что тратит больше всего денег (в целом или внутри выбранной категории).
- **Любимые товары в каждой категории** — три самых частых товара и доля категории в тратах.

Фильтры: год, адрес доставки (Москва / дача), категория. Есть светлая и тёмная тема.

**Как считаются метрики**

- Учитываются только доставленные заказы, отменённые показаны отдельно.
- Сумма трат — сумма поля `amount`, включая доставку и упаковку.
- Средняя скидка = Σ(discount × quantity) / Σ(price × quantity) по товарам (без доставки и упаковки).
- Анализ товаров не включает категорию «Услуги Груши» (доставка, упаковка).

**Как устроено**

- **Vue.js 3** — состояние дашборда (период, адрес, категория, метрика), фильтры, все пересчёты через `computed`, KPI-карточки, топ-листы товаров (с анимацией перестановки `transition-group`) и витрина категорий. Шаблон приложения лежит прямо в `index.html`.
- **d3.js v7** — загрузка CSV (`d3.csv`), агрегации (`d3.rollups`, `d3.group`), шкалы, оси и SVG-графики: помесячная динамика с выбором периода (`d3.brushX`), категории, scatter с раскладкой картинок (`d3.forceSimulation`). Каждый график — Vue-компонент, который перерисовывается при изменении входных данных.

```
index.html          — разметка и Vue-шаблон
css/style.css       — стили, светлая и тёмная тема
js/app.js           — корневое Vue-приложение: состояние, фильтры, расчёты, топ-листы
js/charts.js        — Vue-компоненты с d3-графиками (MonthlyChart, CategoryChart, ScatterChart)
js/utils.js         — форматтеры, тултип, загрузка и агрегация данных
data/orders.csv     — исходный датасет заказов
data/items.csv      — соответствие товара и картинки
img/items/*.jpg     — изображения товаров
AGENTS.md           — описание проекта для OpenCode
```

**Запуск**

Данные загружаются через `d3.csv`, поэтому файл нужно открывать через веб-сервер, а не двойным кликом:

- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root;
- локально: `python -m http.server` в папке проекта и открыть `http://localhost:8000`.

Библиотеки: [d3.js v7](https://d3js.org/) и [Vue.js 3](https://vuejs.org/) — подключаются с CDN, сборка не нужна.
